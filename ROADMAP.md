# Typearchy roadmap

## Shipped in 1.3

- Standalone Linux app launched from the application launcher
- Normal window, optional fullscreen, and Omarchy theme colors
- Local typing practice, Ruby and other code modes, adaptive drills, and history
- Automatic pause when local practice loses focus; paused runs stay out of bests
- Browser and desktop challenges, shared result URLs, replays, and standings
- Optional profiles and reviewed custom passage submissions
- Migration from the old plugin without losing history or account access

## Next

- Broader testing across Linux desktops, screen sizes, and input methods
- Improve the path from a completed test to a useful next practice session
- Expand reviewed prose and code passages with clear source attribution
- History export and import

## Later

- Optional bar companion for shared results, challenges, and score notifications
- Beginner typing and introductory coding lessons
- A separate experience for children, with suitable content and sharing controls

The app is the primary entry point. A companion plugin must remain optional.
Local practice works offline without an account. Online attempts send test input
and timing for validation; public replays contain sanitized passage progress.
