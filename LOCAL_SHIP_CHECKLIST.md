# Typearchy local ship checklist

This pass covers everything that should work without typearchy.com or a hosted
service. Public profiles, challenge URLs, and shared rankings remain separate.

## Engine and input

- [x] Use local calendar dates for personal streaks and UTC dates for Daily
- [x] Preserve comparable challenge identity in each result
- [x] Track character count and personal-best deltas
- [x] Add a local personal-best ghost with live pace comparison
- [x] Support word erase and immediate keyboard restart
- [x] Honor the live-stat preference during play

- [x] Expand Daily far beyond the current short rotation
- [x] Add several prompts per code language
